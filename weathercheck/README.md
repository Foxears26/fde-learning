# Weather Check

Weather Check is a small command-line tool that looks up a city's coordinates and displays its current temperature and weather, along with the forecast for the next three days. It uses the Open-Meteo geocoding and forecast APIs.

## Installation

Install the required Python package:

```bash
pip install requests
```

## Usage

Run the script with a city name:

```bash
python weather.py Toronto
python weather.py Vancouver
```
